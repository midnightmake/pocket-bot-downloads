# Overview
This folder contains STL files for the Pocket Bot.

A great deal of care has gone into making these parts easily 3D-printable with 0.2mm layer heights and no supports needed. Please see more details below.

## Description

This directory contains the following files:

* `chassis.stl`: The main Pocket Bot chassis.
* `marker-mount.stl`: An optional mount for an AprilTag (or similar) that snaps onto the optional expansion header.
* `round-table.stl`: A circular table intended to show off the **Area-Keeping** [example program](https://www.midnightmake.com/pages/pocket-bot-example-programs) by not falling off.
* `wheel-for-motor.stl`: A single wheel meant to be snapped to the Pocket Bot motor axis. **For best results, print this part with TPU or another rubber-like material.**
* `wheel-for-screw.stl`: A single wheel meant to be screwed onto the Pocket Bot to freely rotate. **For best results, print this part with TPU or another rubber-like material.**

Assembly instructions are available [here](https://www.midnightmake.com/pages/pocket-bot-assembly).
