# Pocket Bot Downloads

This repository contains all the firmware, source files, courses, and STLs files you need to get started with the Pocket Bot.

## Contents

* `courses`: Various line and demo courses as seen in the [example programs](https://www.midnightmake.com/pages/pocket-bot-example-programs).
* `firmware`: Complete source code (drivers, firmware, etc.) for the Pocket Bot. Also a great place to start for writing your own.
* `stls`: 3D-printable replacment and expansion parts for the Pocket Bot. Assembly instructions are available [here](https://www.midnightmake.com/pages/pocket-bot-assembly).
